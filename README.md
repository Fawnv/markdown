# Markdown

Лёгкий просмотрщик и редактор Markdown для Windows: показывает `.md` так, как это делает GitHub,
и при этом заменяет Блокнот для обычных текстовых файлов.

- **Просмотр** — GitHub Flavored Markdown: таблицы, списки задач, alerts (`> [!NOTE]`), сноски,
  emoji `:rocket:`, подсветка кода (~200 языков, включая PowerShell, TypeScript, TOML), YAML front matter,
  сырой HTML (`<details>`, `<kbd>`, картинки), светлая и тёмная тема.
- **Raw** — редактор исходника: перенос по словам, поиск с подсветкой, Tab/Shift+Tab для блока,
  автопродолжение списков, F5 вставляет время и дату (как в Блокноте).
- **Рядом** — редактор и просмотр бок о бок с точной синхронной прокруткой.
- Галочки `- [ ]` кликабельны прямо в просмотре — исходник обновляется.
- Файл отслеживается: если его изменили в другом редакторе, просмотр обновится сам.
- Кодировки как в Блокноте: UTF-8 (с BOM и без), UTF-16 LE/BE, ANSI (cp1251 и т. п.); CRLF/LF сохраняются.
- Ссылки на соседние `.md` открываются в том же окне, внешние — в браузере; картинки по относительным путям работают.
- Интерфейс на русском или английском — по языку Windows.

`Markdown.exe` — один файл ~4 МБ, без установщика и рантаймов.

## Установка

```bash
target\release\Markdown.exe --install
```

То же самое есть в меню программы (`⋯` → «Зарегистрировать в Windows…»). Права администратора не нужны,
всё пишется в профиль пользователя:

| Что | Как |
|---|---|
| `Win+R` → `markdown` | `HKCU\…\App Paths\markdown.exe` (тот же механизм, что у `paintdotnet`) |
| Меню «Пуск» | ярлык `Markdown` |
| Двойной клик по `.md` | становится программой по умолчанию, если у `.md` её ещё не было |
| «Открыть с помощью» | `.md`, `.txt`, `.log`, `.json`, `.yaml`, `.ini` и другие текстовые |
| Правый клик по любому файлу | «Открыть в Markdown» |
| Параметры → Приложения по умолчанию | Markdown есть в списке, можно назначить для `.md` / `.txt` |
| «Приложения и возможности» | есть пункт удаления |

Программа копируется в `%LOCALAPPDATA%\Programs\Markdown`. Удаление: через «Приложения и возможности»,
через меню программы или командой `Markdown.exe --uninstall`.

> [!NOTE]
> Windows не даёт программам молча перехватывать ассоциацию, если пользователь уже выбрал другое приложение
> для `.md` или `.txt`. В таком случае выберите Markdown в «Открыть с помощью → Всегда»
> или в «Приложениях по умолчанию».

## Горячие клавиши

| Клавиши | Действие |
|---|---|
| `Ctrl+E` | Просмотр ⇄ Raw |
| `Ctrl+1` / `Ctrl+2` / `Ctrl+3` | Просмотр / Raw / Рядом |
| `Ctrl+N`, `Ctrl+Shift+N` | Новый документ, новое окно |
| `Ctrl+O`, `Ctrl+S`, `Ctrl+Shift+S` | Открыть, сохранить, сохранить как |
| `Ctrl+F` (`Ctrl+H`), `F3` / `Shift+F3` | Поиск, следующее / предыдущее |
| `Ctrl+=` / `Ctrl+-` / `Ctrl+0`, `Ctrl+колесо` | Масштаб |
| `Alt+Z` | Перенос по словам |
| `Ctrl+P` | Печать (и «Microsoft Print to PDF») |
| `F5` | Вставить время и дату |
| `Ctrl+W` | Закрыть окно |
| `Ctrl+клик` по ссылке на `.md` | Открыть в новом окне |

Клик по окончанию строк в строке состояния переключает CRLF ⇄ LF.

## Сборка

Нужны Rust (MSVC toolchain) и Visual Studio Build Tools. WebView2 Runtime уже есть в Windows 10/11.

```bash
cargo build --release
```

```bash
cargo test
```

Иконка берётся из `assets/app.ico` (16–256 px). Чтобы заменить её, положите туда готовый `.ico`
и пересоберите. Из PNG её можно собрать скриптом: квадратный PNG 256×256 или больше в `assets/icon.png`,
по желанию — отдельно отрисованные `assets/icon-16.png`, `icon-24.png`, `icon-32.png`, затем:

```bash
powershell -ExecutionPolicy Bypass -File assets\make-icon.ps1
```

Проверить рендер без окна: `cargo run --example render < README.md > out.html`.

## Как устроено

```
src/main.rs      окно (tao) + системный WebView2 (wry), IPC, файлы, диалоги, слежение за файлом
src/render.rs    Markdown → HTML (comrak, GFM) + подсветка кода (syntect, классы hl-*)
src/textio.rs    кодировки и окончания строк как в Блокноте
src/install.rs   регистрация в Windows (HKCU), ярлык, удаление
src/settings.rs  настройки (%LOCALAPPDATA%\Markdown\settings.json), язык, тема системы
ui/              интерфейс: tokens.css → markdown.css + app.css, app.js
```

Рендерит Rust, WebView2 только отображает готовый HTML. Это не Tauri: используются те же низкоуровневые
crates (`tao`, `wry`), но без фреймворка, Node.js и сборщика фронтенда. Все ресурсы вшиты в exe.

Безопасность: сырой HTML разрешён, как на GitHub, но скрипты не выполняются (строгий CSP плюс очистка
`<script>`, `<iframe>`, `on*`-атрибутов и `javascript:`-ссылок), навигация из окна заблокирована.

Цена движка браузера — память: в Диспетчере задач около 80 МБ, из них сама программа ~4 МБ,
остальное — процессы WebView2. Зато вёрстка совпадает с GitHub, а не «похожа» на него.

## Дизайн-токены

Весь интерфейс построен на токенах из [`ui/tokens.css`](ui/tokens.css), значения взяты из GitHub Primer,
поэтому просмотр выглядит как на github.com. Компоненты (`app.css`, `markdown.css`) не содержат
захардкоженных цветов — только `var(--…)`.

| Группа | Токены | Светлая / тёмная |
|---|---|---|
| Фон | `--bg-default`, `--bg-muted`, `--bg-neutral-muted` | `#ffffff` / `#0d1117`, `#f6f8fa` / `#151b23` |
| Текст | `--fg-default`, `--fg-muted` | `#1f2328` / `#f0f6fc`, `#59636e` / `#9198a1` |
| Границы | `--border-default`, `--border-muted` | `#d1d9e0` / `#3d444d` |
| Акцент и статусы | `--accent-fg`, `--success-fg`, `--attention-fg`, `--danger-fg`, `--done-fg` | цвета alerts NOTE / TIP / WARNING / CAUTION / IMPORTANT |
| Подсветка кода | `--hl-comment`, `--hl-keyword`, `--hl-string`, `--hl-entity`, `--hl-constant`, `--hl-variable`, … | палитра Primer «prettylights» |
| Типографика | `--font-sans`, `--font-mono`, `--font-editor`, `--fs-body` (16px × `--zoom`) | Segoe UI, Consolas / Cascadia Mono |
| Отступы | `--space-1` … `--space-7` | сетка 4px |
| Радиусы | `--radius-sm` / `md` / `lg` | 4 / 6 / 12px |
| Движение | `--duration-fast`, `--duration-base`, `--ease-out` | 80 / 160ms, учитывается `prefers-reduced-motion` |

Компоненты интерфейса повторяют паттерны Primer: SegmentedControl (переключатель режимов),
IconButton (кнопки панели), ActionMenu (меню `⋯`), поле поиска, строка состояния.

## Пока не поддерживается

Формулы (`$…$`) и диаграммы Mermaid показываются как текст или код: для них нужны тяжёлые JS-библиотеки,
и в лёгкую версию они не вошли.
